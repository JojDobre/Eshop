# Šablóna Dielňa

Teplá šablóna pre handmade a remeselné obchody (keramika, sviečky, šperky, pletené veci, mydlá, drevo).
Odvodená od šablóny Default – zdedí všetky funkcie obchodu (varianty, doplnky, pokladňa, účet, bloky).

- Nastavenia: Vzhľad → Prispôsobiť (sekcie úvodnej stránky, texty, fotky, farby). Prázdne texty sa nahradia
  predvolenými textami šablóny v jazyku obchodu (`lang/{sk,cs,en}/dielna.php`).
- Akcentová farba je farba značky obchodu (Nastavenia → Značka).
- Písma sú uložené na hostingu: Fraunces, DM Sans a Caveat (SIL Open Font License).
- Demo „Hlina & Vosk“ (`demo/`): Vzhľad → Šablóny → Dielňa → Nahrať demo.
