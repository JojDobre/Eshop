# Šablóna Esencia

Moderná a farebná šablóna pre kozmetiku a drogériu (pleťová kozmetika, vlasy, telo, make-up, ekodomácnosť).
Odvodená od šablóny Default – zdedí všetky funkcie obchodu (varianty, pokladňa, účet, bloky, blog).

- **Palety** (Vzhľad → Prispôsobiť → Štýl): Koral, Lila, Mäta, Jemná alebo farba značky obchodu. Paleta sa použije
  v celom obchode vrátane košíka a pokladne. Text na farebných plochách je biely alebo tmavý podľa kontrastu.
- **Písmo nadpisov:** podľa palety alebo Bricolage Grotesque, Unbounded, Outfit (uložené na hostingu, SIL OFL).
- Sekcie úvodnej stránky: banner s akciami, rýchly výber podľa potreby, mozaika kategórií, bestsellery, výhody,
  rutina v 3 krokoch (ID produktov v nastaveniach, tlačidlo pridá všetky do košíka), zložky, banner s výzvou,
  recenzie a články z blogu. Prázdne texty sa nahradia predvolenými (`lang/{sk,cs,en}/esencia.php`).
- Cena za 100 ml / liter: produktom nastavte typ s jednotkou liter a objem (Katalóg → Produkty).
- Demo „Lúka“ (`demo/`): Vzhľad → Šablóny → Esencia → Nahrať demo.
