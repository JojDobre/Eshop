# Šablóna Štúdio

Elegantná šablóna pre služby s online rezerváciou: kaderníctva, kozmetické salóny, masáže, nechtové štúdiá,
fyzioterapia či lektori. Odvodená od šablóny Default – zdedí všetky funkcie obchodu (produkty, poukážky, pokladňa, účet, bloky).

- Potrebuje modul **Rezervácie** (služby, zamestnanci s rozvrhom). Služby majú fotku a kategóriu – kategórie sa
  zobrazia ako filter na úvodnej stránke a ako skupiny v cenníku.
- Prepisuje stránky rezervácií (`modules/reservations`): cenník, výber dňa a času so súhrnom a potvrdenie.
- Nastavenia: Vzhľad → Prispôsobiť (sekcie úvodnej stránky, texty, tím, otváracie hodiny, farby). Prázdne texty sa
  nahradia predvolenými textami šablóny v jazyku obchodu (`lang/{sk,cs,en}/studio.php`), texty sa dajú preložiť.
- Akcentová farba je farba značky obchodu (Nastavenia → Značka), v deme zelená #2f4a3f.
- Písma sú uložené na hostingu: Instrument Serif a Manrope (SIL Open Font License).
- Demo „Štúdio Mira“ (`demo/`): Vzhľad → Šablóny → Štúdio → Nahrať demo.
